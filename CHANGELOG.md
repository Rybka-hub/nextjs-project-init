# Historia zmian

Opisujemy tutaj zmiany skilla, jego specyfikacji i dołączonych materiałów. Zmiany przygotowywane do kolejnego wydania zapisujemy najpierw pod nagłówkiem „Niewydane”.

## 1.0.0 — 2026-10-04

Pierwsze oznaczone wydanie skilla `nextjs-project-init`.

- Inicjalizacja przez `create-next-app`, struktura projektu i wzór `.gitignore` w `Nextjs.md`.
- Domyślny zestaw: TypeScript, App Router, Tailwind CSS, ESLint, npm i `src/`.
- Podział danych na `data/input/` oraz `data/output/`, poza publicznymi zasobami.
- Możliwość uproszczenia układu dla małego prototypu.
- Odczyt zasad dokumentacji z globalnych instrukcji lub pomocniczego `Agent.md`.
- README z celem, instalacją, przykładami użycia i zasadami wersjonowania.
- Numer wersji w `SKILL.md`, tag `v1.0.0` i wydanie GitHub.
